# PHP 기업 홈페이지 시연

기적기획 웹퍼블리셔·프론트엔드 공고에 맞춰 만든 기업 홈페이지 시연물입니다.

## 구현 범위

- PHP 배열 기반 서비스·프로젝트 반복 출력
- 시맨틱 HTML5 구조
- 반응형 CSS
- jQuery 모바일 메뉴, FAQ, 문의 폼 검증
- 본문 바로가기, 키보드 포커스, aria-expanded, aria-live
- title, description, canonical, Open Graph, robots 메타데이터
- prefers-reduced-motion 대응

## 실행

```bash
docker compose up --build
```

브라우저에서 `http://localhost:8088`을 엽니다.

## 범위 고지

이 시연물은 PHP와 jQuery 사용 증거입니다. 그누보드는 아직 포함하지 않았으며 포트폴리오에서도 사용 기술로 주장하지 않습니다. 문의 폼은 입력 검증만 수행하며 데이터를 서버로 전송하지 않습니다.
