# 김명원 응용 소프트웨어 개발 포트폴리오

기존 다크 테마와 섹션 구조를 유지하면서 웹, API, 데이터베이스와 운영 경험을 중심으로 최신화한 Next.js 포트폴리오입니다.

## 구성

- 프로필과 개발 전환 배경
- 교육·활동 및 자격
- 실제 적용 범위를 표시한 기술 카드
- 역할과 결과를 구분한 프로젝트 5건
- GitHub, 기술 기록과 이메일 연락처

## 대표 프로젝트

1. 고객상담 AI 품질 개선
2. 수업 커리큘럼 데이터베이스
3. ITPE Quiz 학습 서비스
4. Boda 견적·예약 통합 플랫폼
5. 금융상품 비교 웹서비스

## 실행과 검증

```bash
npm install
npm test
npm run build
npm start
```

- 콘텐츠 검증 테스트 8건
- Next.js 프로덕션 빌드
- 데스크톱과 모바일 화면 확인
