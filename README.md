# 김명원 응용 소프트웨어 개발 포트폴리오

웹과 API, 데이터베이스 구현, 데이터 정합성 검증과 장애 분석 사례를 정리한 Next.js 포트폴리오입니다.

## 대표 내용

- 주식회사 두부 Project Operation팀 AX 인턴 경력
- Boda 견적·예약 통합 플랫폼
- ITPE Quiz 학습 서비스
- 금융상품 비교 웹서비스

## 기술

- Next.js 15.5, React 19, TypeScript
- React Native, React, Vue, Next.js
- TypeScript, JavaScript, Python
- REST API, Django, Spring Boot API
- PostgreSQL, MySQL, DynamoDB, SQL
- AWS, Git, 로그 기반 장애 분석

## 실행

```bash
npm install
npm test
npm run build
npm start
```
